# Security Policy

## Reporting a vulnerability

If you find a security vulnerability in this project, please **do not** open a public issue.

Instead, report it privately via [GitHub's private vulnerability reporting](../../security/advisories/new) on this repository, or by emailing the maintainer directly.

Please include:
- A description of the vulnerability and its impact.
- Steps to reproduce.
- Any relevant logs, screenshots, or proof-of-concept code.

We'll acknowledge your report and follow up with next steps once triaged.
